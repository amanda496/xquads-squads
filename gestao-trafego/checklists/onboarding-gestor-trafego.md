# Checklist Final de Onboarding — Gestor de Tráfego

Use este checklist para garantir que nenhuma etapa foi esquecida antes de declarar o
onboarding como concluído. Nada é marcado como feito sem evidência registrada no dossiê.

**Fonte:** Playbook de Onboarding — Gestor de Tráfego Stark v1.0 (§11) + POP-OPR-013/014.

---

## Pré-Setup
- [ ] Briefing com cliente realizado (persona, procedimentos, localização, preços)
- [ ] Gestor com acesso **Administrador na BM** do cliente
- [ ] Acessos coletados: Meta Business, Google Ads, GA4, GTM, site
- [ ] Ativos Meta **R1–R6** validados, sem restrição — ver `validacao-ativos-meta.md`
- [ ] Cliente informado dos critérios de qualidade do número (80% / 24h)
- [ ] Pasta do cliente criada no Google Drive
- [ ] Grupo WhatsApp criado com foto, descrição e boas-vindas
- [ ] Checklist de novo cliente preenchido (nome, CRM, RQE, procedimentos, endereço)
- [ ] Diagnóstico inicial documentado (8 perguntas + histórico, se houver)
- [ ] Análise de concorrência realizada (3 concorrentes)

## Meta Ads
- [ ] Colunas personalizadas instaladas no Gerenciador
- [ ] TODOS os públicos padrão Stark criados (engajamento, video views, site, lookalikes, interesses)
- [ ] Públicos CRM 180 dias criados (Lead · Lead Qualificado · Consulta Agendada)
- [ ] Público Semelhante 1% criado a partir da etapa mais qualificada
- [ ] Lista de exclusão carregada
- [ ] Nomenclatura padrão aplicada em todas as campanhas (3 níveis)
- [ ] UTMs configuradas em todos os anúncios
- [ ] Posicionamento manual configurado (Feed + Stories) — sem Advantage+
- [ ] Idade manual configurada (nunca Idade Automática)
- [ ] CTA manual configurado
- [ ] Coerência Corpo × Face respeitada em todas as campanhas
- [ ] Estrutura de funil montada: TOFU + MOFU + BOFU
- [ ] Criativos de onboarding subidos com classificação por nível de consciência
- [ ] Pixel verificado e eventos de conversão configurados

## Google Ads
- [ ] Campanhas separadas por Corporal e Facial
- [ ] Termos Genéricos/Institucionais presentes em todas as campanhas
- [ ] Palavras negativas configuradas **ANTES** do lançamento
- [ ] Rede de Display desmarcada em todas as campanhas de Pesquisa
- [ ] Correspondência apenas Frase ou Exata (nenhuma Ampla)
- [ ] 3 RSAs por grupo, 15 títulos + 5 descrições por RSA
- [ ] Extensões completas: Sitelinks (4+), Imagens (3–5), Frases de Destaque, Snippets, Chamada
- [ ] Nenhuma imagem com exposição de pele, cicatriz aberta ou centro cirúrgico
- [ ] Google Meu Negócio vinculado
- [ ] UTMs configuradas no nível de conta e nas extensões
- [ ] Lista de clientes antigos carregada como público
- [ ] Públicos de interesse em modo Observação
- [ ] Estratégia de lances: Maximizar Conversões
- [ ] Localização no raio de atuação real da clínica

## Rastreamento (GTM + GA4)
- [ ] Container GTM modelo importado e configurado
- [ ] 3 variáveis preenchidas: GA4 ID (G-), Pixel ID, Google Ads ID (AW-)
- [ ] Container publicado e testado com Tag Assistant
- [ ] GA4 vinculado ao Google Ads
- [ ] Google Signals ativado
- [ ] `generate_lead` marcado como conversão no GA4
- [ ] API de Conversões configurada
- [ ] Medição Agregada de Eventos configurada

## Operacional
- [ ] Cliente criado no Reportei com Meta Ads, Google Ads e Instagram conectados
- [ ] Planilha de acompanhamento semanal configurada
- [ ] Configurações registradas no dossiê
- [ ] Pendências de acesso documentadas
- [ ] Tarefa de onboarding marcada como concluída no ClickUp
- [ ] Conferência final com Coordenador realizada

---

**RESULTADO:** onboarding só é declarado concluído com todos os itens aplicáveis
aprovados e a conferência final feita. Itens não aplicáveis (ex.: Google Ads quando o
cliente não contratou) devem ser marcados como **N/A com justificativa no dossiê** —
nunca deixados em branco.
